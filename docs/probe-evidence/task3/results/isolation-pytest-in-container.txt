在隔离容器内执行仓库自己的测试套件（2026-09-21）。

目的：证明隔离不是"能拦住写入但干不了活"——qa-executor 的真实工作（跑测试）在
仓库只读挂载 + 无外网的条件下可以正常完成。

命令：
  QA_ISOLATION_IMAGE=localhost/qa-executor:0.1.0 \
    zsh isolation/run-isolated.sh -- python -m pytest tests -q -p no:cacheprovider

说明 `-p no:cacheprovider`：仓库以只读挂载，pytest 默认要写 .pytest_cache，
关掉缓存插件即可；这也顺带证明测试本身不依赖对仓库的写权限。

输出：

........................................................................ [ 30%]
........................................................................ [ 61%]
........................................................................ [ 92%]
..................                                                       [100%]
234 passed in 1.87s
PYTEST_RC=0

与宿主机 `make check` 的 234 项一致（同一套测试，容器内 python 3.12 / 宿主 3.9.6，
结果相同）。
