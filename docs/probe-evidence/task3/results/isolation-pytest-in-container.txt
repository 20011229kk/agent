在隔离容器内执行仓库自己的测试套件（2026-09-21，参数保真与 digest 绑定修复之后）。

目的：证明隔离不是"能拦住写入但干不了活"——qa-executor 的真实工作（跑测试）在
仓库只读挂载 + 无外网的条件下可以正常完成。

命令：
  zsh isolation/run-isolated.sh --print-manifest -- \
      python -m pytest tests -q -p no:cacheprovider

说明 `-p no:cacheprovider`：仓库以只读挂载，pytest 默认要写 .pytest_cache，
关掉缓存插件即可；这也顺带证明测试本身不依赖对仓库的写权限。

`--print-manifest` 打印策略与脚本的 sha256，供核对"跑的是不是这套规则"：
